# Security Policy

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Use GitHub's private vulnerability reporting:
**[Report a vulnerability](https://github.com/kuberik/kuberik/security/advisories/new)**

Include:
- Affected component and version
- Steps to reproduce
- Impact assessment if known

We aim to acknowledge reports within 3 business days and provide a fix or mitigation timeline within 14 days.

## Supported Versions

We patch security issues in the latest release of each component. Older versions are not backported unless the severity warrants it.
